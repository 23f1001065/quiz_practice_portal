# Modern-application-development-2


## Project Details: 
It is an online quiz app for exam preparation for multiple courses. This is a two-user application, one is Administrator and other is regular user or student. A site created forstudent to practice for their exam. They can practice subject wise to chapter wise. They can pick a chapter of their choice and start a quiz from all available quizzes that belongs to that chapter. They can attempt a particular quiz multiple times but there is a time limit, within one hours ofcompleting a quiz they can not reattempt. They must wait for it to reattempt. Every quiz attempt is separately stored to give them an idea of how they are improving on a particular topic.On other side Administrator or quiz-master who can create, update, read and delete quizzes and associated subjects and chapters. So, it is a two-role based application where admin can control quizzes and questions in it. 


## Frameworks and libraries used: - 
The main frameworks and libraries that I have used is 

* **Flask** - A python language-based web app development framework that I have used for application backend. 

* **Flask-Security-Too** – A flask extension for authentication and authorization system 
building. I have used token based with role as security system. 

* **Flask-SQLAlchemy** – Also flask extension for working with ORM based database query system. I define all the database table using a object SQLAlchemy from this 
library. 

* **SQLAlchemy** – Main python sqalchemy library. I have used for attribute type highlighting in model definition for data type. 

* **Pip** – For installing those packages. 

* **Random** – For creating random id of newly registered student. 

* **SQLite** – A database for storing all data that application generate. 

* **VueJs**– A fronted reactive framework for User interface building. 

* **Vue Router** – Also a frontend routing framework to implement route mechanism at UI level. 

* **Vue Store** – For storing global clint data at UI 

* **Bootstrap** – For styling the html page in vue tamplate
